### 思考题复盘每题至少 10 项
原始回答（忠实记录，不改写不美化）→ 参考答案 → 正确的部分 → 错误/不完整/含糊的部分 → 错误的具体原因 → 本题实际考查的知识点 → 正确的分析思路 → 以后遇到同类问题怎么判断 → 变式练习 → 判定与去向（若需重点展开则进入薄弱点展开）。

### 掌握程度分级（严格）
已掌握 / 基本掌握 / 理解不稳 / 尚未掌握 / 待验证。判定标准：一次答对不算已掌握；薄弱点必须有后续验证记录（变式题、后续讲次印证）。

### 薄弱点重点展开（8 项要素）
我具体错在哪里 → 正确理解是什么 → 为什么容易出错 → 正确与错误思路对比表 → 一个简单例子 → 一个容易设陷阱的例子 → 一句便于记忆的判断口诀 → 后续复习建议。

### 动态薄弱点总表（文档开头）
每条：知识点 / 所属讲次 / 当前掌握程度 / 暴露的问题 / 建议复习方式 / 后续验证结果。**已改善的标"已改善"+验证依据，不删除旧记录**；新发现薄弱点追加。

### 其他纪律
- 保留所有历史讲次内容，新内容追加，不覆盖不删除。
- 不虚构用户回答；信息不足时标"待验证"或"待作答"，不假设掌握情况。
- **批改规则（重要）**：用户作答后，直接在聊天里给出批改（疏漏错误 + 标准答案），**不要汇报文档更新内容**（新增了什么、薄弱点状态变化等都不说），文档更新静默执行。
